## Result

The [canonical archive](u06-gui-demand-v1/index.json) verifies 2,132 source seals,
four receipts, worker termination and no resource stop. All three scenarios pass
against the actual sealed rebuilt assets. Actual camera drag changes the canvas
without changing canonical facelets. Animated/reduced playback, rewind, zero-draw
idle, context loss/update/restore, search interaction, narrow editing and both
reference/incomplete export labels pass. No-WebGL playback works. Model failure
preserves the committed step and replay-certified export without a keyboard loop.

Viewport overrides are reset and all three owned tabs are closed. Fixture,
application and native owners stop cleanly, with no forced termination and no
retained IPC directory. The app assets remain unchanged. These are functional
acceptance results, not general CPU/GPU or full resource-enforced browser numbers.

[Review screenshots](review-demand/index.json) show restored 3D, narrow controls,
worker failure and actual camera movement. Operator approval and a review video
