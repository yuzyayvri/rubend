# Reflect the actual optimized solved predicate

The complete unpruned reference is checked, but optimized traversal is not
formally connected to it. This supporting S04 unit handles one concrete part
of that boundary. It adds no domain law, pruning policy or stronger app label.

For every five-word `C.Cubie`, evidence that the actual imported `Search.solved`
returns true yields equality with the actual `C.solved()`. That equality yields
`C.to_facelets(cube)==M.solved()`, then a zero-radius `BRTFound` in the already
checked reference. The reference witness has the empty word and a replay proof.
Its type comes from the real reference module, not a duplicate result type.

The proof directly reflects all five actual U32 comparisons. The alternative
was to import the much larger packed-input/certificate proof just for equality.
The selected helper uses the existing equality kernel and five field rewrites.
It imports each of the seven real search modules and requires their current goal
bodies to match. Each generated profile helper gets a fresh BendTT verdict.
There is no parallel or independent review under solo work.

The implication is deliberately one-way on raw packed words. Padding bits in
corner orientation, the high edge word and edge orientation can be ignored by
facelet conversion while still making `Search.solved` false. Fifty-two concrete
padding representations must exhibit that distinction. A universal converse
over arbitrary packed words would be false. A zero private test packet means
the positive bridge was refused, not that reference exclusion was established.

The fixed checks cover 160 single-bit changes, 470 independently constructed
legal cases, 512 arbitrary raw records, 52 padding cases and the solved case.
All 1,195 inputs run against all seven generated JavaScript profile modules.
Actual comparator-source omissions need concrete false-positive counterexamples
and must break the proof. Wrong reference target, nonempty zero-radius witness
and false converse claims must also reject through both checker entrypoints.
Two actual packet-source faults must fail behavior checks. Default and packed-
small native executables must consume all fields and packets and match the
independent checksum over all 1,195 cases.

The reference, equality kernel and unchanged 87-input root gate are reused only
after source, archive and execution identity checks. Current input validation,
concrete subgroup targets, loaded-data admissibility, canonical cuts, optimized
contour simulation, portfolio interruption and exclusion transport remain open.
This result alone does not discharge any of those obligations or NP04–NP08.

The fixed queue is `u06-search-goal-v1`, estimated four minutes with a twelve-
minute cap. Pure checks and compilation use at most 1.5 GiB and four low-priority
lanes. Finite and native checks use CPU2 and 1 GiB. No table generation, search
benchmark, release holdout, runtime/default change or publishing is included.
