# One-preturn candidate bank

The path [preflight](u04-premove-paths-v1/index.json) passed before this unit.
This private treatment adds one seeded candidate bank, initially a U preturn.
It does not change the product or claim a measured strength gain.

The solo architecture pass compared adding seed metadata to portfolio task axes
with independent portfolio views over one table owner. Choose independent views.
`Lane` contains data-only task/incumbent state. `Session` alone owns the table.
An original lane retains its unmodified six-root round robin and exact task.
A seeded Fast lane uses the existing axis/inverse portfolio for g*U. It gets
one quantum after seven original-lane quanta. Completed/inactive banks do not
take turns. The original lane is never starved. This allocation is frozen,
not a claim that exact progress at equal deadlines is unchanged.

Original and seeded work counts remain separate. Their sum is the experiment's
total search work. No second table, worker or mutable shared array exists.
`bench/bounded-portfolio.bend` keeps normal 20,000/60,000-step quanta and clips
only a final quantum at the shared budget boundary. The disabled bank must
reproduce every frozen control snapshot.

Each bank keeps a valid incumbent for its own root. Global sharing into a child
is not used to invent a local threshold. A seeded answer maps back through
`premove-paths.reconstruct` and normalization. Before changing the original
incumbent, the actual original sticker cube must accept a `Certificate.certify`
replay certificate. Failure stops the private session. A valid shorter answer
uses the original portfolio's existing update/restart/exact-task creation.
The child's lower bound and completion status never become original-root
exclusion evidence. No completed-failure cache or new law is introduced.

Full packed-root equality removes a redundant seeded bank. This only drops
optional candidate work, never original exact coverage. The original six-root
and exact implementation are not replaced. A future quality comparison must
charge every bank's work and setup cost and reject coverage/bound/deadline loss.
