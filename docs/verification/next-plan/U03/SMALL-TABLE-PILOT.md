# Native small edge-distance tables

This is the next U03 feasibility step, not a six-edge database build. The
native Bend generator accepts only `Pilot.One`, `Two` and `Three`. Capacities
are 32, 1,024 and 16,384 cells. Their valid domains contain 24, 528 and 10,560
states. Both complementary patterns use their actual solved ranks, not an
assumed zero goal.

Two designs were considered in the solo architecture pass. A FIFO BFS needs
a second owned array. A layered sweep needs repeated scans but little scratch.
Use the sweep for this small auditable reference, without assuming it scales.
The pure `Build` state distinguishes active traversal from finished output.
A 32-layer fuel cap bounds work. Unseen cells hold 255. Out-of-range targets
are rejected before array access, because Bend array indexes wrap.

`bench/edge-pattern-table.bend` owns traversal and distance writes. The isolated
native entry is generated by `bench/generate-edge-table-pilot.mjs`. It builds
six tables. Native controls deliberately exhaust fuel, use an invalid goal
and emit invalid transitions. None may report completion.

`tests/edge-table-oracle.mjs` builds an independent KPuzzle/FIFO reference.
The audit requires full entry equality, unique zero, complete coverage, all
directed-edge inequalities and decreasing paths. Three actual table corruptions
must fail. No product solver is replaced by the reference implementation.

Native elapsed generation intervals are forced before the ending timestamp.
Each table is generated once. They are planning costs, not a before/after
speed comparison. Host run-plus-audit time and sampled native RSS are separate
fields. Initialization, lookup marginality, full-build scratch, checkpointing,
compression and end-to-end quality remain open.

The fixed queue is `u03-pilot-u04-events-v1`. Expected duration is five minutes,
with a fifteen-minute hard cap and at most three GiB. Compilation and the
unchanged proof checks use four low-priority lanes. Native table and contour
jobs run serially on one lane. Source seals and canonical receipt verification
precede any later edits. No large build, NP05 claim, production bound, holdout,
publication or independent review is included.

The batch [passed canonical verification](u03-pilot-u04-events-v1/index.json)
with 1,911 source seals, all four receipts and clean worker exit. All six tables
equal the independent reference, covering 22,224 entries and 400,032 directed
edges. Diameters are three, five and six for each pattern's one-, two- and
three-edge domains. Every non-goal has a decreasing path. All three native
refusal controls and all three corrupted tables are rejected. Both pure modules
pass BendTT and the unchanged `just check` gates pass.

Each three-edge table took one observed native generation interval of 120 or
122 ms. One-edge samples hit the zero-ms timer resolution. These are single-run
planning observations, not precise throughput estimates or speedup evidence.
Sampled native RSS reached 3,380 KiB. No full build, compression, engine lookup
or conditional pruning result follows from this pilot.
