# Admit the actual packed root after a certificate

The certificate-reaching bridge recovers a typed reference word for an original
facelet input. This unit checks the remaining root representation boundary.
It does not assume that validator success proves a packed refinement.

`admit(facelets, packed, certificate)` reconstructs the typed root from the
actual accepted certificate. It compares all five U32 packed words with that
root's checked packing. A successful comparison is reflected into equality,
not retained as an unexplained Boolean. `PCTWitness<facelets, packed>` ties one
reaching word to both the original facelets and the exact supplied packed cube.
Failure returns `None`. No new pruning path consumes this witness yet.

Both forward facelet correspondence and the actual `Cubie.inverse` view follow
from that witness and the existing packing/inverse proofs. No inverse callback
or validator-completeness premise is introduced. Equality requires all 160 bits,
including otherwise ignored padding. A matching display alone is insufficient.

The alternative was proving all validator outputs correct before accepting any
root. Exact post-certificate comparison supplies the narrower fact needed here
and refuses mismatches without relying on that unfinished general theorem.
The private generated module leaves production modules and caches unchanged.

## Fixed checks

Focused Bend and BendTT checking passes. Noncommuting `R U` input admits its
actual packed root and refuses a flipped edge-orientation bit. A native smoke
entry compiles and executes with the expected checksum 285,219,522. It uses a
named data case and a single-owner list, avoiding the earlier certificate
fixture's invalid pair-list type.

The queue is `u02-packed-certificate-v1`, expected three minutes within a
thirteen-minute cap. It uses at most 3 GiB and four low-priority build lanes.
Finite and native checks use CPU2. It reuses archive-bound certificate, packing,
inverse and pilot artifacts. No old timing comparison is repeated.

Both proof entrypoints must reject five actual omitted-word comparison sources
and three invalid witness or view sources. Separate emitted copies of the
actual mutated comparison function must expose all five omissions. Those are
comparison-kernel controls, not full-admission implementations.

The finite plan covers 1,024 word-derived inputs and all 55 saved pilot answers
on four reused roots. It checks actual validator outputs, forward/inverse replay,
10,240 single-bit refusals, wrong roots, failed certificates, 256 raw equality
cases and padding changes with identical facelets. A native entry checks 570
admission packets against independently specified outcomes and their checksum.
Source generation must be deterministic. Existing 23 laws and toolchain gates
remain unchanged.

This is not universal validator completeness, coordinate-target linkage,
loaded-distance admissibility, optimized traversal certification or a speed
result. No production inference, new domain law, database, holdout, publication
or independent review is included. The final report and no-push order remain.

## Boolean adapter recovery

The first queue passed the complete proof job and all sixteen negative
entrypoints. Its finite test then used a tagged Bool read on a primitive
JavaScript boolean. The actual assertion reported `undefined` instead of
`'False'`. This was a test adapter error, not a packed equality failure.

The [failed run](u02-packed-certificate-v1-failed/index.json) preserves 2,716
seals and both receipts. Its extra compressed snapshot contains the completed
proof record, pure and negative sources, templates and old adapter. Read
[the ABI defect](../../../issues/packed-comparison-boolean-abi.md).

The recovery queue is `u02-packed-certificate-v2`, expected two minutes with a
seven-minute cap. It changes only three Boolean reads, checks actual true/false
exports and reproduces the original assertion. Unchanged proofs and modules
are reused by hash, including byte-identical copies into fresh paths. All
finite/native checks and unchanged gates still run. The original stays failed.

## Result

The [recovery archive](u02-packed-certificate-v2/index.json) verifies 2,751
source seals and three receipts, worker gone and no resource stop. All 1,079
admissions and inverse comparisons pass, comprising 1,024 word-derived cases
and 55 saved answers on four reused pilot roots. The 10,240 single-bit refusals,
64 wrong-root refusals, 64 failed-certificate refusals, 256 raw equality cases
and three display-preserving padding refusals pass.

All five actual omitted-word kernels have counterexamples. All 570 native
packets match the independently specified checksum 141,886,355. The sixteen
false-proof entrypoints, frozen Boolean-ABI regression and unchanged 23-law
and toolchain gates pass. Proof/module copies are byte-identical. Earlier
failed status and source snapshots remain unchanged. No production pruning,
performance acceptance or independent review follows.
