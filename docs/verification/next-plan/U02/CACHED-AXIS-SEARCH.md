# Source-isolated cached-axis search

The [conditional diagnostic](u02-pipeline-v2/index.json) passed with 1,604
matching seals, no resource stop and its worker gone. Its 8,352 permitted
root-near edges show why eager coordinate updates are the wrong control.
At residual nine, 4,675 edges stop at the first forward joint lookup. At
residual ten, 236 stop there. These are modeled conditional counts on the
fixed sample, without earlier small-bound cuts. They are not tree frequencies
or measured costs.

## Representation and ownership

`bench/generate-axis-search.mjs` generates an isolated copy under `build/`.
Its `Node` retains the packed cube and the original three coordinates. Six
flat U32 fields hold FB and RL twist, flip and slice coordinates. The generator
checks all 43 original Node occurrences and their ten-field shape. Its manifest
binds original sources and every generated file. Production sources, optional
profile selection, sealed tables and the established laws stay unchanged.

The original small-bound and forward-UD stages run first. After UD passes,
three existing transition reads update FB with the rotated move. After FB
passes, three more update RL with the twice-rotated move. The existing inverse
policy then runs unchanged. An accepted child stores the six computed values.
A rejected child restores the original parent, including its original cache.
There is no extra rank reconstruction on acceptance and no repeated transition
lookup to recover discarded child coordinates.

The organizing structure is the existing search frame. Model the Domain shaped
that choice. A separate record around each packed cube would allocate another
object and change more than the six retained coordinates. The flat alternative
keeps frame ownership in Search. Build the Lever shaped the reproducible
generator and its source-shape refusal instead of a hand-maintained Search fork.
These alternatives were examined sequentially under the solo restriction.
Independent architecture review did not run.

## Fixed functional experiment

The generated native control, candidate and candidate audit use 4,096 work
steps and target twelve. Each runs the existing 163 frozen shallow cases,
then the first eight pilot and first eight development cases. The release
holdout is not read. Workers run serially against the existing raw joint cache.

Snapshots retain every original stack field and all metadata, not just the
incumbent length. The comparison rejects a changed node count, lower bound,
answer, cube or stack order. Six negative controls check those comparisons,
including missing data. Candidates replay through the existing model adapter.
The separate audit recomputes all nine coordinates from the top packed cube
before every search advance. A mismatch ends with ProfileMismatch and fails
the driver. Audit timing is never used as performance evidence.

The candidate pure module and audit module pass Bend and BendTT. The first
candidate worker compiles natively. A forward helper ordering failure is saved
in the [failed typecheck receipt](u02-axis-search-precommit-v1/u02-axis-search-type-v2.json.gz),
then corrected before the passing v3 and v4 checks. The
[preflight](u02-axis-search-precommit-v1/u02-axis-search-v1-preflight.json.gz)
passes generator reproducibility, six comparison rejection controls, the
unchanged root verdict and all sixteen toolchain checks. Full native state
equivalence and emitted allocation
inspection are pending in the next batch. Compilation is not that verdict.
