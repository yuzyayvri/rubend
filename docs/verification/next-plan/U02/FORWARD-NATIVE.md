# Private forward complete-coverage experiment

The [actual-entry screen](INFERENCE-INFORMATION.md) shows substantial candidate
information. This next unit implements one isolated treatment, forward complete
coverage only. It does not integrate production pruning or combine inverse
masking, coordinate retention, table changes or task ordering.

The actual current FullCube pipeline reads three forward joint bounds before
inverse checks. If all three equal a positive remaining child radius, their
proved reference subgroup move masks cover all eighteen final moves. The
candidate refuses that child. A one-bit tightness accumulator carries the first
two equalities to the existing last lookup. No stack/metadata fields or table
reads are added. Zero remaining depth must still admit the solved child, and
the unknown nibble fifteen must never construct this inference.

## Design and ownership

The caller is the existing last forward-bound admission. It receives the
original parent frame and the last value, plus the accumulated tightness flag.
Only RawInverseThree and FullCube can select the additional gate. All ordinary
next-move predecessor logic, inverse checks, replay and completion code stay
unchanged. No forward final-move mask is interpreted as a next-move mask.

Model the Domain puts this transient property in the bound pipeline rather
than the long-lived search frame. Two designs were considered solo. Retaining
all three bounds in every frame would change ownership, allocation and timing
attribution. Passing one tightness flag along the existing lookup chain keeps
this first treatment separate. Independent architecture review does not run.
The deterministic source-isolation generator checks every edited definition's
exact text and preserves original production sources and the inverse module.

The generic NP01/NP02 reference laws and the finite independent DAG are evidence
for the mechanism, not a formal refinement of loaded raw data or the optimized
enumerator. Those concrete proofs remain open. This is a private executable
candidate under test, not a stronger certified solver or enabled product bound.
No new domain statement or established-law change is added.

emitted gate must agree on 61,440 staged bound/radius triples, 240 goal/profile

and profile. Actual gate tests must reject each mutated executable module.
Twelve record corruptions test missing data, replay, known optima and completion.
These are semantic runtime negatives, not rejected theorem proofs.

and inspect emitted C for owned-array mode. Both receive the same existing
sealed raw table, one native thread and 200,000 advance calls per request.
Initialization and original solver work stay present. This is not yet a timing
comparison and no native duration is promoted from these single functional runs.

An independent integer sticker-geometry BFS supplies all 3,502 states through

Each side must return all 3,758 exact lengths and lower bounds, and every answer
must independently replay. Four fixed pilot and four development roots add
deeper running or completed cases. Their fuel-censored states remain censored,
not failed correctness or proof of completion. The unselected RawJoint profile
must preserve every state/result on the 262 roots through depth two.

Four serial native owners execute 8,056 requests. Preserve every result, failure,
answer, binary/C digest, scope and worker cleanup. No overlapping table owner,
browser or benchmark is admitted. Stop each native and remove its IPC before
starting the next. The source-identical raw data and all 87 root inputs are
