# Exact-work safety and incremental inverse reference laws

The existing interior-work measurements do not justify adding a production
cache. The existing partition ledgers already retain missing, failed and retried
work without claiming global completion. This unit proves the approved NP06,
NP07 and NP08 semantic contracts while leaving the selected engine unchanged.

## Failure reuse keeps the exact root and context

`CompletedFailure` means that every permitted solving word within the supplied
radius is absent. It is a quantified predicate, not a cache-entry constructor.
NP06 composes two checked Nat inequalities. A word within a smaller radius
would also be within the completed radius, contradicting the failure witness.
The exact-key theorem transports a witness only through equality of the entire
cube and context. A digest, partial cube or equal numeric bound is not equality.

The context parameter contains the complete permitted-path policy. Its initial
runtime instance must fix FullCube, profile, bound policy, contour/session epoch
and previous-move history. Interrupted, incumbent-truncated and root-mask work
does not acquire a failure witness from these theorems. Full-key comparison,
replacement and eviction remain runtime responsibilities. No cache is added.

## Every required partition must exclude all its admitted words

`RequiredIndex` has a checked finite range. The empty required set has no index.
`Representative` carries the selected partition, a complete word from the
original root, a no-longer-than-original proof, the original radius proof,
partition admission and actual solving equality. Complete words include every
partition prefix. They are not suffix-only worker lengths.

Coverage must supply such a representative for every solving word within the
contour. `AllCompleted` must exclude every admitted word in every required
partition. NP07 combines those witnesses to exclude all short solutions and
proves the lower bound `depth + 1`. Missing, failed, pending or duplicated runtime
status records cannot inhabit this quantified exhaustion predicate by a label.
Symmetry coverage must still supply its real equal-or-shorter transformation.

The original radius proof is returned in the coverage representative. This
preserves its content under affine ownership instead of copying it or weakening
the condition. A nonvacuous actual U-turn instance establishes lower bound one
at contour zero through the proved move/inverse law.

## Inverse maintenance uses the left action

NP08 quantifies word-presented legal typed reference states. The existing
inverse-snoc law reverses and inverts the appended move. Existing typed cube
composition then proves `inverse(g*m) = inverse(m)*inverse(g)`.
The reconstruction theorem transfers a solving word through this exact update.
It reuses actual inverse-word cancellation, not an inverse callback premise.

Finite checks compare the actual emitted reference functions with independent
facelet replay. The R-then-U example distinguishes U'-then-R' from the incorrect
R'-then-U'. Ordinary right-move coordinate updates are not accepted as left
actions. No optimized dual state or new move mapping is installed here.
