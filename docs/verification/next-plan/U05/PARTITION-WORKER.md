# Bounded native partition worker

The prefix census and ledger have finite checks, but their earlier exhausted
events were synthetic. This unit connects actual native subtrees to that private
ledger. It does not update the application's global lower bound.

Use the unchanged FullCube/RawInverseThree search and the existing sealed raw
cache. One worker owns one table across fixed jobs. Each scope binds the root,
contour4, frontier2, epoch, table digest and exact worker/search policy digest.
Required prefixes come from the checked census and actual root mask. The separate
short job searches lengths zero and one. A prefix job carries its complete
reversed global path, total prefix length, last face and remaining radius two.
Do not apply root symmetry again to the prefix child.

The pure wrapper classifies before each actual Search.advance. A found incumbent
is a hit even if the stack is empty. Empty stack with no incumbent is exhaustion.
Nonempty work at fuel end is partial. Stop before Search.next can begin a new
contour. No wrapper result can be inferred from a counter alone. Emit a real
original-root replay certificate for every hit, always without a global optimum
label. Native result kinds remain distinct.

The host checks every ordered job/start/result pair against its immutable scope.
Only an actual started, matching, empty-stack no-hit result can become exhausted
in the existing ledger. A partial job cannot close its slot. A hit retires the
scope. Later records may still be checked as batch diagnostics but cannot close
that retired contour. Missing, duplicated and stale records fail admission.
Existing ledger transitions and domain guards remain unchanged.

Check solved, U, R, U R, a commutator and one previously used uniform pilot root.
Compare every complete subtree's hit existence with an independent unpruned
suffix enumeration under the same move-history rules. Replay all native hits.
Fuel-zero and fuel-one probes must stay partial. Compare complete no-hit scope
closure with the required manifest; never substitute a completion counter.
Source-bound refusal and early-exhaustion corruption controls precede acceptance.

This is finite protocol and native-search evidence. It does not prove loaded-data
admissibility, universal coverage, NP07 or general search completeness. A private
ledger's complete value is not a production or formal optimality certificate.
No new distance table, domain law, worker pool, parallel gain or public API change.
Independent review is not run under solo work.

The worker's owned request file is capped at512KiB. The existing application's
input limit is unchanged. A batch is capped at twelve minutes and3GiB, including
the2-GiB native raw-profile array, with one low-priority worker lane. Compilation
may use four lanes. Hash and identity-check the existing raw file before and
after; do not copy or regenerate it. The actual run remains pending.

The fixed batch is `u05-worker-v1`, expected four minutes. Five synthetic
classifier packets, seven admission refusals and two actual source corruptions
precede the raw-table run. A compiled early-exhaustion worker also runs the two
partial probes and must fail host admission. Twelve record corruptions plus
missing-manifest and stale-scope controls use saved actual records afterward.
The raw digest is streamed inside the resource-limited job. Do not add the1.1-GB
payload to the outer queue's synchronous source-file hasher. The plan declares
its exact external-data identity instead. Prefix and ledger sources/artifacts
must match their existing verified build records before reuse.

## Result

The [canonical archive](u05-worker-v1/index.json) verifies2,447source seals and
four resource receipts. The worker is gone and no resource stop occurred.
All1,124jobs are accounted for. Five hit paths pass the actual replay certificate
and independent host replay. The unpruned oracle checks213,933states across
complete jobs. Both fuel probes stay partial. The raw hash and identity checks
pass before and after, and both native processes exit normally.

The no-hit pilot scope applies all244required exhaustion receipts and its private
ledger returns complete. Five hit scopes retire and remain incomplete. The host
checks323identical exhaustion retries. Twelve record corruptions, missing-job
and stale-scope controls fail admission. The actual early-exhaustion native
corruption is rejected. The five classifier packets, seven refusal controls,
second source corruption, pure wrapper verdict and unchanged proof gates pass.

This establishes the bounded native-to-ledger protocol on these cases. It does
not establish NP07, a universal exhaustion certificate, a production lower bound
or multicore scaling. The next unit checks isolated worker ownership and retry
convergence with the same source-bound jobs and saved oracle, without rebuilding
the native search or generating data.
