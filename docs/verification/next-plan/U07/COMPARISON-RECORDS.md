# Comparison-record preflight

U07 preparation starts with conventions, not the release holdout. The existing
native/warm adapters have useful source seals and lifecycle checks. The old
Nissy smoke tool is a cold-process reference, not a matched warm comparison.
`cubing/search` is the installed two-phase reference. It is not automatically
the separately pinned upstream Java min2phase revision.

The record model distinguishes a solved empty path from no path. Candidate
arrival times determine deadline eligibility. A late verified path remains in
the record but cannot improve deadline coverage. A timeout may retain an earlier
verified answer. Errors, unavailable solvers and missing answers remain in the
planned denominator. Unknown lower bounds remain null, not an invented zero.

Require plain HTM face notation and independent replay against the original
input. Reject rotations, wide/slice moves and unparsed metadata. A half turn
costs one. Search-established, reference-reported and unestablished optimality
are distinct. Replay alone never admits formal optimality. The two-phase
reference cannot claim an optimum through this adapter.

Every paired case fixes its input hash, request, budget, timer boundaries,
initialization inclusion, memory ceiling, affinity and thread count. Source
identity stays fixed per solver. Require every planned case/cohort/solver row,
including unavailable results. Reject missing/duplicate rows, drift and mixed
cold-process/warm-request samples. Preserve five alternating cohort orders.

Two designs were considered. A shared end-to-end timer would hide different
initialization and request lifecycles. Normalize explicit source-bound records
with distinct clock modes instead. Solver execution and lifecycle adapters stay
separate from the pure record/scoring model. No generic adapter may relabel a
fixture as a measured result.

This first unit accepts fixture evidence only. It checks solved, single-half-turn
and short-word inputs, deliberately absent/late/timeout results and corrupted
metadata. No solver, source download, table generation or release-case access is
performed. No performance result or final configuration is selected. Measured
adapters, pinned competitor identities, resource receipts and the final freeze
remain later work. Existing proof, independent-review and publication gates stay
unchanged.

The fixed queue is `u07-records-v1`. The focused spot check passes 45 fixture rows,
fifteen malformed-record controls and ten aggregate controls, plus seven notation
refusals. The detached queue repeats those fixed checks and unchanged proof gates.
Estimate one minute with a five-minute cap and at most 3 GiB, serial low-priority
jobs. No actual comparative measurements are admitted by this record model yet.

The [canonical archive](u07-records-v1/index.json) verifies 2,332 seals and both
resource receipts. The worker is gone with no resource stop. All 45 fixture rows,
fifteen record corruptions, ten aggregate corruptions, seven notation refusals
and unchanged proof/toolchain gates pass. No solver process, measured comparison
or release-case evaluation was performed.
