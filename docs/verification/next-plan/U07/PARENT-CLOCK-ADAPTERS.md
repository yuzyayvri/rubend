## Clock ownership

`ComparisonActor` timestamps each complete stdout frame with its parent's
monotonic clock, before parsing or post-run independent replay. A split frame
receives its completion time, not its first byte time. Late candidates remain
raw evidence but cannot receive deadline credit. Cold requests start before
process spawn and queue their input during initialization. A hard cold deadline
stops the sandbox and leaves incomplete initialization censored. Warm requests
start only after actual readiness and keep initialization separately recorded.

Rubend uses the delivered `Engine` and native binary. Its production validation
and candidate replay remain part of the answer path. They are not subtracted
from latency. The min2phase readiness barrier includes a verified solved sentinel
that forces its real lazy initialization. Muodov, Nissy and vcube retain loaded
native parents from the checked library adapters. Timed-out min2phase workers
restart before the next warm request. One active request owns each actor.

All real actors run in private user, PID, IPC and network namespaces. Runtime,
binary and cache mounts are read-only. The repository is not mounted. Readiness
and shutdown capture process-start identities, and Rubend's PID-root IPC path
is checked after normal shutdown. The installed default, bundled min2phase,
Muodov C, Nissy h48h0 and vcube 108 are five different comparison families.
Vcube 104 and preserved U00 small, inverse and h0 are extra configurations,
not extra solver implementations. All actor artifacts are tied to canonical
delivery, setup and native-service records. No table is regenerated.
