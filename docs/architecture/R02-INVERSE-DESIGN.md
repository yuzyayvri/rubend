# Lazy inverse-bound pilot

This is a solo experimental design, not a default-engine promotion or a new
formal optimality claim. The user prohibits agents. No independent review runs.

The R02 file boundary expands to a pure inverse-bound module, benchmark worker
and comparison programs, inverse tests, the test recipe, and a fail-closed
observer variant. These support the approved exact-only pilot. The benchmark
programs are not installed application backends. No cube representation, move
math, cache bytes, application protocol, or existing domain law changes.

The selected design recomputes a cube inverse only after the three forward
joint estimates admit a full-cube child. Compare one inverse estimate with up
to three, stopping at a sufficient cut. Reuse the audited raw cache. Keep the
existing forward profile as the control. No new table or foreign math is added.

The alternative maintains normal/inverse positions and updates the latter with
premoves. Defer it until measured inversion cost justifies the extra frame state
and its multiplication-order/refinement obligations.

Use flat RawInverseOne and RawInverseThree profile constructors. They deliberately
combine the selected raw layout and exact-estimate policy to remain inline
zero-field values. A heap-allocated policy object shared through every metadata
copy could add reference-count traffic. Explicit variants also force geometry
dispatch updates when a profile is added.

The inverse-bound module returns a named CubeBound rather than an unqualified
phase-reduction estimate. This is a goal brand, not an admissibility proof.
The search boundary applies it only to FullCube frames. Reduction and Subgroup
frames bypass it. Phase-one reduction still uses its own single-axis estimate.
The inverse's distance to that subgroup can exceed the original reduction
distance. U R is a concrete proposed counterexample to test.

The correctness argument uses inversion-invariance of full-cube distance under
the inverse-closed eighteen-move set, the raw table's admissibility, and correct
packed inverse/projection operations. Existing universal bridges remain
unfinished. Add no new law without approval and weaken none of the eighteen
established laws. Validate packed inverses independently and exercise the goal
guard before timing. Recheck shallow exact optima and completed-depth outcomes.

The existing observer does not model inverse cuts. Its source contract now
intentionally refuses a changed search. Unsupported profile observations also
fail closed. Do not relabel its forward-only counters as inverse diagnostics.

Changed pruning invalidates equal-work-step speed comparisons. Use time to a
declared completed depth/lower bound, known-optimum completions, and fixed-budget
quality. Preserve errors, incomplete contours, CPU time, wall time, and memory.
The R01 fixed timer explicitly selects RawJoint and must not be mistaken for
an inverse-profile benchmark.

The measurement program owns one raw table and accepts one explicit profile at
worker startup. It constructs a full-cube ExactContour root directly, with no
incumbent and lower bound zero. It advances until a declared target lower bound,
a replay-checked optimum, or twenty million work steps. The loop checks after
each real search transition. Native metadata echoes the selected profile.
This separates contour exclusion from portfolio scheduling and answer finding.
It does not measure the full application's anytime behavior.

Compare this with the alternative of fixed-duration application jobs. Those
remain required before promotion, but are a poor first mechanism test because
the serial portfolio divides time between improving and exact tasks. The target
program exposes time to exclude identical depths and retains fuel-exhausted
jobs. It uses existing IO and loader functions, not new foreign effects.

The independent packed-inverse test compares two thousand uniform legal cubes
with cubing's inverse transformation. A separate facelet BFS enumerates all
46,741 states through depth four and checks inverse state and inverse distance.
Synthetic all-fifteen words test goal dispatch only. They are not distance data.

The native raw-table check confirms the U R counterexample and checks fourteen
cutoffs on one thousand walk states. It compares lazy early-stop decisions with
all three inverse projections. The walk is deterministic, not uniformly sampled.
The separate inverse-main entrypoint uses the normal application worker and
portfolio with RawInverseThree for deadline checks. The default app stays light.
